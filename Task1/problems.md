# Проблемные зоны

## Запись пациента на приём
- Передача личных данных пациента (ФИО, дата рождения, телефон, e-mail) по телефону или электронной почте без использования шифрования  
- Ведение журнала записей в Excel без ограничения прав доступа  
- Отсутствие контроля за действиями сотрудников (кто создал, изменил или удалил запись)  
- Все сотрудники имеют возможность доступа к файлу с данными пациентов  
- Отсутствует политика по хранению и удалению устаревших записей  
- Данные при хранении и передаче не защищены шифрованием  
- Нет защиты от копирования файлов на внешние устройства  

## Приём и проведение анализов / обследования
- Медицинские карты и результаты анализов хранятся в виде незашифрованных сканов  
- Нет разграничения доступа к медицинским данным — врачи могут просматривать чужие карты  
- Результаты обследований отправляются по электронной почте без шифрования  
- Отсутствует подтверждение подлинности отправителя лабораторных документов  
- Нет централизованной базы данных для хранения медицинской информации  
- Отсутствует аудит доступа к личной медицинской информации (PHI)  
- Данные хранятся разрозненно в форматах Excel, PDF, JPG  
- Не проводится обезличивание данных  

## Обработка платежей
- Финансовая информация дублируется в Excel и 1С  
- Отсутствует разграничение полномочий между кассиром и бухгалтером  
- Финансовые отчёты передаются по электронной почте без использования цифровой подписи  
- Нет резервного копирования и контроля целостности бухгалтерских данных  
- 1С функционирует в файловом режиме без централизованной базы данных и журналирования
